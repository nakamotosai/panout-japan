# tokyo-crime-map 项目基本法（PROJECT_CONSTITUTION.md）

> 立项：2026-10-05（由 `F:/omp-data` 实验区转正）；生产根 `F:/projects/tokyo-crime-map`。

## 这是什么

警视厅町丁别认知件数 + 住基人口 → 手动分级 choropleth + 详情卡。
区市面 62 + 町丁面 5234，默认进町丁面，覆盖整个东京都。纯静态站（`site/` + `http.server` 即看）。

## 非目标

- 不做后端：无服务器、无数据库、无账号。
- 不自编聚合口径：警视厅 6 个「計」列原样呈现（删掉过自编「租房相关」，不恢复）。
- 不追照片级渲染：canvas 渲染 + 抽稀后面（偏差 ≤1.5m），就绪 ~0.6s 优先。

## 技术路线（已拍板，不重议）

1. **一图一指标 + 绝对标尺**：9 级 YlOrRd，`log(1+r)` 等距 8 断点 + p99 封顶；
   每指标一把尺子（区市 R7+R8 + 町丁 R7+R8 全并），换时间/换图层不断点，同色=同危险度。
2. **零膨胀单独一档**：零占比 ≥35% 的指标（入室/粗暴/凶恶）零独占最低档，剩下 8 色在非零段。
3. **缩放永不自动切层**：只认按钮；点面/搜索/卡片跳转可切。
4. **深色独立调色**：暖黑底 `#16130e` + 深棕分隔线，YlOrRd 深色下提亮 15%，断点与浅色同一套。
