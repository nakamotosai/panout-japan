## 口径（一图一指标）

- **两级手动切**：`区市面`（62面：23区+多摩26市3町1村+岛2町7村）/ `町丁面`（5234面）。
  缩放**永不**自动切层，只认按钮；点面/搜索/卡片跳转可切。
- 颜色=所选罪种每千人件数，**绝对标尺**（按“值”切，不按“个数”切）：9 级 YlOrRd
  `#ffffcc→#ffeda0→#fed976→#feb24c→#fd8d3c→#fc4e2a→#e31a1c→#bd0026→#800026`，
  `log(1+r)` 等距 8 断点 + p99 封顶（极值不再拉飞整条带，封顶值写进图例 `≥xx`）。
  - 每指标一把尺子：样本=区市(R7+R8)+町丁(R7+R8)全并，换时间/换图层**不断点**，同色=同危险度，跨指标/时间/图层可比。
  - 零占比 ≥35% 的指标（入室/粗暴/凶恶）：**零独占最低档**，剩下 8 色在非零段 log 等距；图例注明「零案件单独一档」。
  - 断点严格递增。旧分位数方案已删：它按每档 20% 个数切，8.2 和 1331 会同为最深色（162 倍差距不可辨）。
- 町丁面 `pop<200` 不参色（画浅灰，防丸の内/公园/办公街畸变）。
- 罪种切：全部/非入室/入室/粗暴/凶恶/其他（=警视厅「計」列原样：総合計/非侵入窃盗計/侵入窃盗計/粗暴犯計/凶悪犯計/その他計）；时间切 R7年计/R8累计；图例=该指标绝对标尺（不跟时间/图层跑）。
- 点面进详情卡（全罪种行 + 回区市）；搜町丁直飞面；区市卡出「町丁 Top」可点入。
- 顶栏是**实占位**（地图 `top: var(--hh)`，`--hh` 由 `syncHeaderHeight()` 写、ResizeObserver 跟随图例换行），
  Leaflet 缩放控件因此不会被固定顶栏盖住；右侧卡片仍是浮层，`fitTokyo()` 给它让位；
  `zoomSnap:0.25` 分数级缩放（z10.75）填满可用区域，整都四角都在图内。

## 自检

```bash
python scripts/qa_data.py                       # 数据层 21 项（口径/完整性/标尺/同步）
python scripts/qa_site.py --retries 6           # 页面 72 项（无头 Chromium，端到端）
```

- `qa_data.py`：区市↔面对齐、町丁↔点位一一对应、无面=无坐标、属性齐全、分档单调、
  六指标绝对标尺 8 断点严格递增且 9 色用满、危险/安全不同色回归（8.2 vs 1331）、坐标范围、
  `data/` 与 `site/data/` md5 一致、缓存覆盖。
- `qa_site.py`：默认态、档位切换、缩放不切档、12 组指标×时间、搜索（含 Enter/Esc/点外部/无匹配）、
  无面町丁、岛屿、区市卡 Top 跳转、悬停读数（只更新左下 readout、不动面样式）、选中同色加深互斥（白边恒定）、回区市、色带分布、初始视野不被顶栏/卡片压住、手机版。
- 本机注意：重复启动 Chromium 时驱动进程偶发被杀（`Connection closed while reading from the driver`），
  非页面问题，故脚本整轮自动重试；备用是用 omp `browser` 命名空间开托管 tab 跑同样检查。

## 验收（实测）

- `python scripts/qa_data.py` → 21/21 PASS；`python scripts/qa_site.py --retries 6` → **72/72 PASS**（D3 危险/安全不同色 + E2 换时间不断点 + M1 九色用满 + T1–T8 深色）。
- 深色模式：顶栏 `深色` 按钮切换，`localStorage` 记住选择，默认浅色。深色=暖黑底 `#16130e` + 深棕分隔线 + YlOrRd 提亮 15%，断点与浅色同一套（颜色可比）。
- 选中样式=同色加深（`shade()` 等比压暗约 24%，白边恒定），悬停零描边。
- 默认进町丁面，卡片 `新宿区歌舞伎町2丁目 · 296.4/千人 · 人口1,960`；图例带「町丁档」。
- 区市面 62 全有数；八王子市卡出 8 条「町丁 Top」（中町 245.3/千人）→ 点入进町丁卡。
- 搜 `町田` → 12 项町丁 + 区市 → 点入 `町田市つくし野1丁目` 卡；Enter/点外部/Esc/重聚焦都通。
- 无面町丁 `新宿区三栄町` 卡片正常（注明「暂无町丁界」，无残留加深）；岛（伊豆大島/三宅/八丈/小笠原）面正常渲染。
- 6 指标 9 色全部用满（如全部 R7：最浅 101 面 → 最深封顶 56 面；凶恶 R7：零 4292 面独占最浅 + 剩下 8 档全有面，不再是 2 色）。
- 绝对标尺断点（R7/R8/区市/町丁通用）：全部 `[0.7, 1.9, 4.0, 7.5, 13.6, 23.9, 41.5, ≥71.6封顶]`；
  凶恶 `[0独占, 0.14, 0.28, 0.45, 0.63, 0.84, 1.07, ≥1.3封顶]`。8.2（橙 `#fc4e2a`）vs 1331（最深 `#800026`）已可辨。

- 就绪 ~0.6s（canvas 渲染器 + 抽稀后数据）；桌面/手机截图已看；console 零报错。
