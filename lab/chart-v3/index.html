方案 A

一层画完阴影、分界、区间名全部由同一个自定义系列在同一帧里画出

把现在这三层东西(阴影 markArea / 分界 markLine / 名字 graphic)合成一层: 共用同一次坐标变换、同一张画布,所以永远不会错位、不会晚一帧。名字字号分成固定档位, 只有缩放停手后才换档 —— 拖动过程中绝不跳号;名字放不下时渐隐,不缩字号也不越界。

  • 怎么玩:拖底部滑条 / 滚轮平移 / Shift+滚轮缩放
  • 拖动中注意:字号一动不动,停下约 0.2 秒才可能换一档
  • 分界虚线永远贴在它那个区间真实的第一个数据点上
  • 代价:全期間(14 任挤一条轴)字号会压到 11px —— 这是「区间内印字 + 字号统一 + 名字齐全」三者的物理上限,想要大字就得看 B / C
方案 B

政权书脊顶部政权色带当书脊,姓永远印得下、字号永远 13px

把「区间名」搬出绘图区,放进顶部一条政权色带:段宽永远够印两个字, 固定字号不可能跳号,分界从书脊一路贯穿到绘图区 —— 书脊、分界、折线是同一套坐标。 主图因此可以只留折线,更干净;顶部用明朝体大字显示当前政权,窗口一变就横向切换。

  • 怎么玩:点某个色带段没有绑跳转,拖动仍走底部滑条 / 滚轮
  • 拖动中注意:色带里的名字大小、位置都绝对稳定
  • 顶部大字 = 当前窗口里占得最多的那一任内阁
方案 C

自绘引擎不用图表库,手写 Canvas 渲染器:惯性、橡皮筋、可拖总览条

完全自己画:窗口(时间范围)是唯一真相源,阴影、分界、折线、标签都由同一个映射算出。 交互按金融图表的做法:拖拽平移带惯性、滚轮左右移动时间轴、Shift+滚轮以光标为锚缩放、滚到头即停(不回弹)、双击复位、 底部总览条可以直接拖窗口或拖手柄、十字线磁吸到最近一次调查点、按 f 看帧率。

  • 怎么玩:拖图表平移 · 滚轮左右移动 · Shift+滚轮缩放 · 双击复位 · ←/→ 平移 · 0 复位 · f 帧率
  • 手感是重点:松手后会有惯性滑行;滚到两端就是两端,不会弹回来也不会抖
  • 底部那条是总览条:拖动窗口、拉两端手柄都能改范围
方案 D

书脊 + 引擎B 的信息设计 × C 的自绘引擎,两块合起来

顶部政权书脊做成圆角胶囊(姓恒 12.5px、永远放得下,分界只画在绘图区里、不在胶囊之间加线); 引擎是 C 那套自己写的 Canvas:拖拽带惯性、滚轮左右移动时间轴、Shift+滚轮以光标为锚缩放、 滚到头就停住、不回弹不抖动、双击复位、底部总览条可拖窗口/拉手柄、十字线磁吸最近调查点。 书脊段可以直接点 —— 点哪一任,就把那一任的任期铺满视窗。

  • 怎么玩:拖图平移 · 滚轮左右移动 · Shift+滚轮缩放 · 双击复位 · 点书脊段跳任期 · 总览条拖窗口/拉手柄 · ←/→ · 0 复位 · f 帧率
  • 滚到最右/最左就停住:实测终点与数据端点差 0 天,松手后 1.8 秒零漂移
  • 已去掉常驻的「当前政权」大字(你点掉的那个);要看具体月份就悬停,十字线会磁吸到最近一次调查点并给读数
